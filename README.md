## Featured Projects
 
### ♟️ Explainable AI Chess Engine
A fully playable engine that pairs a **CNN position evaluator** with classical heuristics and a **Ridge regression** model trained against Stockfish evaluations. It uses batched inference with one-ply lookahead, and a Flask app shows live analysis, top moves and **Integrated Gradients** explanations.
`Python` `TensorFlow` `Scikit-Learn` `Flask`
 
### 🎙️ VERA: Real-Time Voice AI Agent
A conversational voice agent built on **Gemini Live** and **Twilio**, with dynamic multi-tool orchestration mid-call, a **RAG** pipeline for grounded answers, structured conversation memory and latency-tuned response flow.
`Gemini Live` `Twilio` `RAG` `Tool Orchestration`
 
### ⚖️ Legal NLP Knowledge Graph System
An end-to-end legal intelligence platform that extracts entities from judicial documents, builds knowledge graphs and supports case analysis through **hybrid retrieval** (semantic search plus graph reasoning). Classification decisions are explained with **SHAP** and **LIME**.
`Python` `spaCy` `BERT` `NetworkX` `Streamlit`
 
### 🎭 [Emotion Detection](https://github.com/gautham-balaji/Emotion-Detection)
A real-time facial emotion detection system using a CNN, OpenCV and Haar cascades, served through a camera-enabled Flask web interface.
`Python` `OpenCV` `Flask`
